## 项目列表 / Projects

### 1. TikTok店铺自动化工具 / TikTok Shop Automation

基于Python的TikTok店铺自动化工具，支持自动登录、热门商品数据抓取等功能。

**功能特性：**
- 🔐 自动登录TikTok店铺
- 📊 抓取热门商品列表（支持瀑布流）
- 💾 多格式数据存储（Excel、CSV、JSON）
- 🛠️ 支持影刀RPA、Playwright、Selenium

**快速开始：**

```bash
cd tiktok_shop_automation
pip install -r requirements.txt
playwright install chromium
python main.py
```
